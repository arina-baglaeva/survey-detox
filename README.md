## 📋 Описание проекта
Веб-приложение на Python (Streamlit) для сбора и анализа данных о цифровых привычках студентов.  
Тема выбрана из методического пособия по учебной практике 2026.

## ОПИСАНИЕ ПРОЕКТА
Веб-приложение на Python (фреймворк Streamlit) для сбора и анализа данных о цифровых привычках студентов. Тема выбрана в соответствии с методическим пособием по учебной практике 2026 (Тема 2: Цифровой детокс среди студентов).
**Цель проекта:** изучить экранное время студентов, выявить симптомы цифрового перегруза, оценить уровень стресса и проанализировать опыт попыток снижения времени использования гаджетов.
## КАК ЗАПУСТИТЬ ПРОЕКТ
### Требования:
- Python версии 3.8 или выше
- Учетная запись Google для работы с Firebase
**Файл ключа доступа** serviceAccountKey.json 
### Установка и запуск:
1. Скачайте или клонируйте папку проекта на компьютер.
2. Откройте терминал в папке проекта и установите все необходимые библиотеки командой: pip install -r requirements.txt
3. Поместите файл serviceAccountKey.json в корневую папку проекта (рядом с app.py). Внимание: этот файл содержит секретные ключи и не должен передаваться третьим лицам или загружаться в открытые репозитории.
4. Запустите приложение командой: streamlit run app.py
5. Откройте в браузере локальный адрес: http://localhost:8501
## СТРУКТУРА ОПРОСА
Анкета содержит 10 вопросов, направленных на сбор количественных и качественных данных:
- Возраст респондента
- Пол
- Курс обучения
- Среднее количество часов в день, проводимых в социальных сетях
- Уровень стресса от цифрового перегруза (шкала от 1 до 10)
- Симптомы цифрового перегруза (множественный выбор: тревога без телефона, бессонница, усталость глаз, снижение концентрации, раздражительность, отсутствие симптомов)
- Опыт попыток снизить экранное время (успешно / безуспешно / не пробовал)
- Основное используемое устройство (смартфон, планшет, ноутбук, ПК, всё одинаково)
- Частота проверки телефона в течение часа
- Использование телефона перед сном
Дополнительно предусмотрено поле для свободного комментария.
## АНАЛИТИКА И ВИЗУАЛИЗАЦИЯ
После сбора данных в приложении доступен режим аналитики (переключатель "Показать аналитику"). Система автоматически загружает ответы из облачной базы данных Firebase Firestore, очищает их и строит интерактивные графики с помощью библиотек pandas и plotly:
1. Гистограмма распределения часов, проводимых в соцсетях
2. Диаграмма размаха (box plot) уровня стресса
3. Круговые диаграммы: распределение по полу, основному устройству, использованию телефона перед сном и опыту цифрового детокса
4. Столбчатая диаграмма частоты проверки телефона
5. Рейтинг наиболее распространённых симптомов цифрового перегруза
6. Автоматический расчёт средних значений и процентных соотношений
7.📥 **Экспорт данных в формате CSV** — кнопка скачивания в режиме аналитики позволяет выгрузить все ответы в таблицу с корректной кодировкой (utf-8-sig) для открытия в Excel без искажений кириллицы.
## ВЫВОДЫ ПО РЕЗУЛЬТАТАМ ОПРОСА

На основе собранных данных будут сформулированы следующие выводы:
- Среднее экранное время студентов и его корреляция с уровнем стресса

- Доля студентов, предпринимавших попытки цифрового детокса, и их успешность
- Влияние использования гаджетов перед сном на общее самочувствие
- Практические рекомендации по снижению цифровой нагрузки
